01 / แนะนำชุดเมนู

ใส่งบ แล้วให้ระบบแนะนำชุดให้

กรอกเพียงงบขายต่อกล่อง (รวมค่าส่งแล้ว) จำนวนกล่อง และต้นทุนค่าส่งรวมงาน แล้วกด “แนะนำชุดเมนู” ระบบเลือกเฉพาะเมนู/ชุดอาหารที่เจ้าของบันทึก เปิดใช้ และยืนยันต้นทุนครบเท่านั้น ตรงตามรายการที่เจ้าของจัดไว้ ไม่เพิ่มอาหารหรือเปลี่ยนกล่องเอง และไม่ใช้เรทโซนเดิม รายการที่ยังไม่พร้อมจะถูกข้ามและแจ้งใน “รายการที่ถูกข้าม” (บันทึกเมนู/ชุดที่หน้า จัดการเมนู)

ค่าส่งเว้นว่าง = ยังไม่ทราบ ระบบไม่คำนวณจนกว่าจะระบุค่า (กรอก 0 ได้ถ้าไม่มีค่าส่งจริง) · ค่าใช้จ่ายอื่นไม่บังคับ เว้นว่าง = ไม่นำมาคิด · กำไรแสดงเป็น “กำไรหลังหักต้นทุนที่ระบุ”

02 / ข้อมูลงาน

เริ่มจากงบลูกค้า

งบลูกค้าและราคาขายที่เสนอเป็นคนละค่า ไม่กรอกแทนกันอัตโนมัติ

ต้นทุนภายในนี้เป็นข้อมูลสำหรับร่างชุดอาหาร ยังไม่รวมค่าแรง ค่าใช้จ่ายอื่น หรือค่าจัดส่ง

03 / ออกแบบชุด

เลือกและปรับชุดอาหาร

กด “ส่งเข้าแบบฟอร์มแก้ไข” จากผลแนะนำด้านบน แล้วระบบจะคัดลอกให้เฉพาะชุดที่ส่งมาเท่านั้น ระบบตรวจเกณฑ์กำไรใหม่ทุกครั้งที่แก้

04 / ตัวเลขสำหรับเจ้าของ

ตรวจต้นทุนก่อนเสนอ

05 / ข้อความสำหรับลูกค้า

ตรวจข้อความก่อนคัดลอก

ส่วนนี้แสดงชื่อและจำนวนไข่หรือท็อปปิ้งต่อกล่อง พร้อมชื่อชุด อาหาร จำนวน และราคาขายที่ระบุ แต่ไม่แสดงต้นทุน กำไร หรือบันทึกภายใน หากราคาขายของชุดนั้นรวมค่าจัดส่งแล้ว ระบบแสดง “รวมค่าจัดส่งแล้ว” พร้อมยอดรวม และไม่บวกค่าส่งซ้ำ

คัดลอกอย่างเดียว ไม่ส่ง LINE หรืออีเมลอัตโนมัติ
